
# 🚀 Entradas y Salidas C/C++

Este programa muestra en consola entrada y salidas de diversas lineas de tiempo

## 🛠️ Requisitos e Instalación

Para compilar y ejecutar este proyecto necesitas:
* Un compilador de C++ (MSVC C++23 en adelante).
* **Visual Studio Code** con la extensión de C/C++.

### Configuración en VS Code
Este repositorio ya incluye las configuraciones necesarias en la carpeta `.vscode`. 
1. Abre la carpeta del proyecto en VS Code.
2. Presiona `Ctrl + Shift + B` (o `Cmd + Shift + B` en Mac) para compilar.
3. Presiona `F5` para iniciar la depuración.

## 📦 Cómo usarlo

EL programa pedira en consola la entrada de nombre y edad y luego mostrara la información
